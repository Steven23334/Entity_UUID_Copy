# Entity UUID Copy

[![Available on GitHub](https://wsrv.nl/?url=https%3A%2F%2Fcdn.jsdelivr.net%2Fnpm%2F%40intergrav%2Fdevins-badges%403%2Fassets%2Fcozy%2Favailable%2Fgithub_vector.svg&n=-1)](https://github.com/Steven23334/Entity_UUID_Copy)

A lightweight utility addon that lets you copy entity and player UUIDs directly to your system clipboard — no more digging through logs or typing UUIDs by hand.

## 📦 New Content

- **Entity UUID Copier**
  Right-click any living entity (maid, zombie, player, etc.) with this item to copy its UUID to the system clipboard. A chat message confirms the copy. Ideal for commands, configs, or debugging.

- **Player UUID Copier**
  Right-click to open a searchable player list GUI. It shows every online player's name, UUID, and avatar. Type in the **name search box** or the **UUID search box** to filter the list, then click any row to copy that player's UUID.

- **Two Search Fields**
  The player list has independent search fields for **player name** and **UUID**, so you can narrow down by either — or both — at the same time. UUID matching ignores hyphens, so you can paste raw hex fragments.

## 🎯 Purpose

- Provides a fast, in-game way to obtain UUIDs for commands, datapacks, or configs.
- Avoids alt-tabbing to server logs or external tools.
- Lightweight and dependency-free (only requires NeoForge).

## 🔧 Installation

1. Make sure **NeoForge 1.21.1** is installed.
2. Place the `.jar` file of this mod into the `.minecraft/mods` folder.
3. Launch the game.

## 🎮 Usage

- Obtain the item via command:
````
/give @s entity_uuid_copy:entity_uuid_copy
/give @s entity_uuid_copy:player_uuid_copy  
````
- Or find them in the **Tools & Utilities** creative tab.
- **Entity UUID Copier**: right-click any living entity → UUID copied to clipboard.
- **Player UUID Copier**: right-click → player list GUI → search or click to copy.

## ⚙️ Configuration

No configuration file is required. All behavior is built in.

## ⚠️ Requirements

- **Minecraft Versions**: 1.21.1
- **Required Mod Loader**: [NeoForge](https://neoforged.net/) 21.1.188 or higher
- **No other mod dependencies**

# 实体 UUID 复制器

[![可在 GitHub 上获取](https://wsrv.nl/?url=https%3A%2F%2Fcdn.jsdelivr.net%2Fnpm%2F%40intergrav%2Fdevins-badges%403%2Fassets%2Fcozy%2Favailable%2Fgithub_vector.svg&n=-1)](https://github.com/Steven23334/Entity_UUID_Copy)

一个轻量的实用工具模组，可以把实体或玩家的 UUID 直接复制到系统剪贴板 —— 不用再翻日志或手敲 UUID。

## 📦 新增内容

- **实体 UUID 复制器**  
  手持该物品右键任意生物（女仆、僵尸、玩家等），即可把它的 UUID 复制到系统剪贴板，聊天栏会给出提示。适合用于命令、配置或调试。

- **玩家 UUID 复制器**  
  右键打开一个可搜索的玩家列表界面，显示所有在线玩家的名字、UUID 与头像。可以在**玩家名搜索框**或 **UUID 搜索框**中输入内容过滤列表，点击任意一行即可复制该玩家的 UUID。

- **双搜索框**  
  玩家列表界面提供**玩家名**与 **UUID** 两个独立搜索框，可以单独或同时使用。UUID 匹配会忽略连字符，因此可以直接粘贴不带 `-` 的十六进制片段。

## 🎯 模组用途

- 提供一种快速、游戏内获取 UUID 的方式，用于命令、数据包或配置。
- 不必再切到服务端日志或外部工具中查找。
- 轻量、无额外依赖（仅需 NeoForge）。

## 🔧 安装方法

1. 确保已安装 **NeoForge 1.21.1**。
2. 将本模组的 `.jar` 文件放入 `.minecraft/mods` 文件夹。
3. 启动游戏即可。

## 🎮 使用方法

- 通过命令获取物品：
````
/give @s entity_uuid_copy:entity_uuid_copy
/give @s entity_uuid_copy:player_uuid_copy
````
- 或在创造模式 **工具与实用物品** 标签页中找到。
- **实体 UUID 复制器**：右键任意生物 → UUID 复制到剪贴板。
- **玩家 UUID 复制器**：右键 → 玩家列表 GUI → 搜索或点击复制。
